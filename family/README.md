# 「あの時代、家族に何が起きたか」アンケート　自由記述の分類

不況と雇用の世代間アンケート（2026年10月20日〜11月3日実施）の自由記述欄（Q25「当時のこと、今も続いていることを自由にお書きください」）を、内容ごとに分類した結果です。

## 対象

- 回答総数：74件
- 集計対象：73件（不自然な回答1件を除外）
- 自由記述のあった回答：**50件**

## 分類の方法

- 1件の記述に複数の内容が含まれる場合は、当てはまる分類をすべて付けています（複数分類）。そのため、件数の合計は50件を超えます。
- 分類は、選択式の回答ではなく、自由記述に書かれた内容だけをもとに付けています。
- 分類は1人の作業者が行ったもので、複数人での照合はしていません。

## 主な傾向

- **最も多かったのは「非正規の固定化・正社員になれない」（21件）**で、自由記述の4割を占めます。「正社員になれない」「派遣でしか雇ってもらえない」「契約満了のたびに職場を転々とする」といった短い記述が多く見られました。
- **進学・進路の制約（7件）**では、親の収入減や廃業によって進学をあきらめた、通える範囲の学校を選ぶしかなかった、という声がありました。
- **家族への経済的負担（5件）**では、親の治療費や家計、きょうだいの学費を、社会人になってから負担したという記述がありました。
- **支えになったこと・幸運だったこと（7件）**も寄せられました。職業訓練で学んだ技能、社会保険のある職場、恵まれた会社との出会いなどです。
- 「チャンスは何度もあった」と個人の選択を重視する意見も1件ありました。

## 分類ごとの代表的な記述（要約）

原文ではなく、個人が特定されないよう要約・一部省略したものです。

**C 非正規の固定化・正社員になれない**
- 中小企業の正社員だったが、資格を取っても30代後半からは派遣しか決まらない。
- 正社員の機会がなく派遣に落ち着いた。同じ職場で同世代の有名大卒が働いていることに驚く。

**A 進学・進路の制約**
- 親の収入減で大学進学をあきらめたが、就職への切り替えが遅れ、新卒で就職できなかった。
- 学力的に行ける大学ではなく、実家から通える大学を選ばざるを得なかった。

**E 賃金・昇給・待遇の低さ**
- 入社時に「管理職の給料を上げるため若手は据え置く」と言われ、翌年に年功序列が廃止されて基本給が上がらなかった。

**G 家族への経済的負担**
- 社会人になってから、親の治療費や家計、きょうだいの養育費を負担した。

**F 資産形成・生活費・老後の不安**
- 中途で正社員になったため退職金が少なく、派遣期間が長かったため年金も少ない。

**M 支えになったこと・幸運だったこと**
- 卒業後に入社した会社が倒産。職業訓練校で学んだ技能が今も役立っている。

**N 個人の努力や選択を重視する意見**
- チャンスは何度もあった。仕事を選り好みして非正規を抜け出せなかった人もいるのではないか。

## プライバシーへの配慮

- 全文版PDFは、回答者の言葉を残すため原文のまま掲載しています。ただし、アンケートで社名を書かないようお願いしていたため、実在の社名は〔社名省略〕としています。病気や家族の死・暴力など、つらい内容を含む記述があります。記述の内容は回答者個人の経験や意見です。
- 絞り込みページとCSVは要約です。要約では、実名・社名・地名・具体的な金額、病名や診断名、家族の個人的な事情の詳細を除いています。
- IDは、元の回答データ（回答日時など）とは結び付けられないように振り直しています。

## 注意事項

- X（旧Twitter）などでの呼びかけに応じた、自己選択による回答です。統計的な代表性はありません。
- 自由記述は任意回答のため、書いた人の経験や関心に偏りがあります。
- 件数は「その内容に触れた人がいた」ことを示すもので、世代全体の割合を示すものではありません。
